# 多姿势五图评审报告

完成版默认交付可离线打开的单文件 HTML。至少两个经核实的不同姿势，且每个姿势都须展示试穿合体图、应变图、材料应力图、接触压力图和褶皱折角图。用户指定更多姿势时逐一满足五类。每类至少提供一张可判读的真实图，按任务所需补正背面或局部。写明姿势、视角、取证来源和图注，保留原色标和单位。

## 先验收证据再签出报告

清单为 UTF-8 JSON，使用 `poses` 数组。每条姿势需有唯一的 `label`、可追溯的 `source` 和记录同版工程、面料、模特及实际动作的 `setup`。五类图分别填入 `fit`、`strain`、`stress`、`pressure` 和 `fold`。每组包含以下信息：

- `status` 由评审者核实后填写 `verified`。
- `assets` 是图像列表，每张填 `path`、`source`、`view`、`caption`。图像放在清单所在目录或其子目录中。
- `fit`、`stress`、`pressure` 填 `method`。`stress`、`pressure` 还需填写 `unit` 与 `scale`。具体 kPa 读数以同版求解器导出或记录点测为准。

从技能目录运行：

```sh
python3 scripts/verify_review.py 证据清单.json
```

脚本在缺姿势、缺图、文件无效或重复用于不同姿势或类别时退出 2 并列出问题。另须目视核对图是否来自正确的姿势和模式。把没有通过的交付标记为阶段结果，并附本次缺项，已有发现可以保留。

## 主报告内容

先给主要发现和证据，再放统计。按姿势展示五图。有可靠线稿时附同视角对照，有相关数据时附纸样、缝线和局部放大。对比同一裁片或局部时说明单位、分母、阈值和权重。结尾给出最值得先试的变量、位置、依据、复测姿势与验收信号。优先一次改一个变量，用户选定后再改版。

可运行 `python3 scripts/inline_report_images.py 草稿.html 报告.html` 内嵌证据图。交付前离线核对各姿势的五图、图注和色标，检查图片能解码、原比例保留、窄屏布局可读。根据实际使用情况附 JSON、CSV、VTK 或纸样依据。
