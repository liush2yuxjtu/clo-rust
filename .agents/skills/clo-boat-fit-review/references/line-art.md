# 线稿与成衣外观对照

## 确认参考与工程

- 从用户提供的图、文件或设计网页中确认款式、版本和视角。保存的网页可能把线稿放在内联 SVG 中。检查正文、图注和样式。提取时保留原始比例、笔画及相关样式，并检查渲染结果。只找 `img` 会漏掉这类插图，可同时检查 `svg` 和 `figure`。必要时把内联 SVG 另存，补齐原页面的笔画颜色，再用本地渲染器生成 PNG。macOS 可运行 `qlmanage -t -s 1600 -o <目录> <svg 文件>`，并打开结果确认线条完整。线稿用于对照造型。衣长、袖长和口袋位置的尺寸以有单位的纸样或工程量测为准。
- 优先用本轮保存的基准姿势和普通材质快照。记录工程名、裁片、面料、姿势和视角。用 CLO Rust MCP 的 `compare_line_art` 或 Boat 报告配对原图。若引用另一工程版本，只用于该版本的外观复核，在图注注明来源与可比范围。

## 取得可比图像

- 先配对线稿实际提供的视角，通常是正面。同姿势的斜侧和背面可以补充说明，但应标明视角。保留原始快照。并排时等比缩放，用肩、腰线、口袋、袖口或下摆作视觉定位。需要判断细节时附局部放大图并标明裁切范围。
- 使用普通材质显示的已保存快照。检查着色覆盖层、目标部位、模拟状态、缝线和面料。分别记录线稿所画的扣合方式和截图可见的门襟叠合。工程里的实际扣合状态不明时照实标记。

## 解释与复测

- 在 HTML 报告正文内嵌并排图。给图像和保留的原始快照加上来源、工程版本、姿势和视角标签。按项目需要检查前襟和扣位、领座和驳头、口袋、袖口、下摆和垂感。先记录直接看得到的差异，再用同版的纸样、缝线、扣件、面料或支撑设置核对可能原因。
- 线稿缺少比例时，只描述相对位置和轮廓。画面里的扣子不清、领口软塌或褶皱只能说明可见外观，涉及扣件是否存在、纸样是否一致或支撑是否正确的判断需要工程证据。有相关试穿证据时，把它与该项外观判断对应起来。例如，线稿画出双排扣而快照中前襟只在腰部靠拢时，先指出叠合和扣合状态差异，再查工程是否实际建立了扣件与闭合。两版二维外轮廓一致时，仍需核对缝合、面料和支撑。
- 若原因未明，提出一个可复验的变量，例如仅调整扣合位置并观察前襟叠合与下摆开口。经用户选择后在副本上改动，复拍相同的姿势、相机、裁切和显示模式，同时检查相关试穿指标。
