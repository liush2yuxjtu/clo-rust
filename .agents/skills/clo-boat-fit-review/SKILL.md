# 纸样与试穿复核

沿用 `clo-dxf-fit-review` 的证据判读、线稿对照、选布和改版流程。纸样与几何复核用 CLO Rust MCP 或 Boat Linux VM。按用户指定的尺码、姿势、面料、输出和语言工作。输入只读，另设工作和交付目录。保留原版，用户选定方案后在副本上执行改版。

## 完整评审的硬性验收

- 至少 **两个经核实的不同姿势**。优先用基准姿势和最能暴露目标问题的动作。用户指定更多姿势时，所有指定姿势都纳入验收。不同镜头、倒放的同一帧或改名的同一姿势只算一个姿势。
- **每个姿势必须有五类经过核实的实际图像**：试穿合体、应变、材料应力、接触压力、褶皱折角。普通材质图、线稿、缝合截图和同一图的复制件不能代替五类图。接触压力和材料应力分别使用原生图或经过验证的等效求解器输出。参考应力或静态相交只能作为补充证据，不能计入未经验证的类别。
- 保存逐姿势证据清单，交付前**必须运行** `python3 scripts/verify_review.py <证据清单.json>`。只在退出码为 0，且已目视核对姿势、同版来源、显示模式和色标之后，才标记为完整评审。缺项时先获取授权范围内的证据并重验。仍缺项就标注「未通过完整评审」，列出具体姿势、缺图和补采动作。
- 仅核查一张图、缝合或单个姿势的工作走相应的单项工具，可另交阶段发现。单项检查不能用这个技能的完整评审状态交付。

## 从哪里开始

- **DXF 或纸样文件夹**：核对比例、净缝线、裁片、丝缕和缝合定义。用经核实的转换结果或相应的纸样边与缝线导出做 Rust 审核。需要独立准备裁片、网格或姿势时按[运行入口与文件交接](references/runtime.md)选路。
- **已有工程或模拟结果**：确认工程版本、裁片、模特、面料、网格和缝合组。核对每个姿势的同版快照、服装 GLB 和五类图。只有工程文件或存档不全时，按验收要求补采。
- **有设计线稿、技术平面图或设计网页**：按[线稿与成衣外观对照](references/line-art.md)核对视角、来源和扣合状态。在外观对照会影响结论时才追查缺少的参考。

## 选择并确认基准面料

需要按纸样选布、换料或比较候选时，按[按纸样选布](references/fabric-selection.md)核对原版要求、净松量、穿脱和丝缕，给首选、替代和验证条件。按[布样与模拟验证](references/fabric-verification.md)比较同版同姿势的已保存换料结果，记录物性来自实测、供应商还是预设。有指定面料且仅复核试穿时，沿用该面料作为基准。

## 试穿与验证

1. 为每个姿势从同一基准重开或核对保存状态，固定纸样、模特、面料和网格设置。查看实际成衣与姿势，围绕本次问题选取对应动作。
2. 按[运行入口](references/runtime.md)采齐每个姿势的五图，并用 Rust 复核应变和折角。需要缝合、线稿或局部对照时补入对应证据。跨姿势核对裁片 ID、拓扑、单位、阈值和视角。
3. 按[报告规范](references/report.md)运行验收脚本，查看每个姿势的五类图后交付。用图和量测给出最值得先试的变量、部位、依据、复测姿势或条件及验收信号。用户选定后再改版。
